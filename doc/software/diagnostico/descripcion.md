# Diagnóstico WOLF ARC

El sistema WOLF ARC incorpora un módulo de diagnóstico interno que permite supervisar el estado de todos los componentes en tiempo real.

## Información monitorizada

- Estado energético (voltaje, corriente, temperatura)
- Estado de cómputo (carga, disponibilidad)
- Estado de comunicación (latencia, BER, QoS)
- Integridad del cable WolfLinkP
- Eventos de resiliencia (N–1, N–2)

## Objetivos del diagnóstico

- Detectar anomalías antes de que afecten al sistema
- Registrar eventos para auditorías
- Facilitar mantenimiento predictivo
- Garantizar la estabilidad del sistema

## Características

- Logs internos automáticos
- No requiere intervención del usuario
- Compatible con cualquier topología WOLF ARC
